# ALL TOUR: оңтайландыру есебі

Архивтің бастапқы көшірмесімен салыстырылды. Архивте және жұмыс жолының ата-аналарында AGENTS.md табылмады. Бастапқы ZIP өзгертілген жоқ. package.json және package-lock.json өзгермеді; push/deploy орындалмады.

## Өзгерістер

- Hero бастапқыда бір сурет сұратады: eager + high priority. Келесі сахналар scroll прогресі 0,17 және 0,50 болғанда, олардың 0,29/0,62 ауысуларынан бұрын жүктеле бастайды. Батырмамен тікелей ауысу да алдын ала жүктеуді іске қосады. Декодтау біткенше алдыңғы фон сақталады; кеш жүктелген фон біртіндеп көрінеді. Кері айналдыруда жүктелген суреттер сақталады. Reduced-motion режимі сақталды, онда тек келесі сурет алдын ала сұратылады.
- HomePage, AboutPage, DestinationPage, ReviewsPage, FinalCTA және модаль/маршрут суреттеріне қолданыстағы WebP нұсқалары, srcSet/sizes қосылды. Төмен орналасқан сторис суреттері lazy жүктеледі. Бұрынғы aspect-ratio және бекітілген контейнерлер сақталды; бірінші экранның басты суреттері lazy емес.
- TourDetails, StoryLightboxModal, TourCompareModal React.lazy арқылы тек ашылғанда сұратылады. Жүктелу және chunk қатесі кезінде де модаль жабылады, Escape/фокус тұзағы/фонды inert ету жұмыс істейді. Салыстыру батырмасы DOM ішінде сақталып, жабылғаннан кейін фокусты қайтаруға мүмкіндік береді.
- ScrollProgressIndicator әр scroll оқиғасында React render жасамайды: requestAnimationFrame ішінде transform жаңартады. ResizeObserver/resize биіктік өзгерісін ескереді, listener/observer/frame тазаланады. Hero-ның бұрынғы rAF, өлшемдерді кэштеу және тек сахна өзгергенде state жаңарту тәсілі сақталды. Басқа әсерлер жойылмады.
- UpcomingDepartures: to параметріне endDate беріледі. Толық мерзімнің формаға және WhatsApp мәтініне RU/KZ тілдерінде берілуі тексерілді.

## Өлшемдер

Бірдей lockfile, Node 24.21.0, npm 11.19.0 және npm run build қолданылды. kB = 1000 байт, MB = 1 000 000 байт. Бұл файл өлшемдері; нақты желі уақыты емес.

| Көрсеткіш | Бұрын | Кейін |
|---|---:|---:|
| Негізгі index JS | 464,692 kB | 429,981 kB |
| Барлық JS чанктары | 590,849 kB | 597,046 kB |
| CSS | 84,083 kB | 84,259 kB |
| Build ішіндегі барлық суреттер | 24,860424 MB | 24,860424 MB |
| Hero: 480w нұсқалары, JS іске қосылғаннан кейін бастапқы сұрау бюджеті | 83,834 kB / 3 сурет | 18,080 kB / 1 сурет |
| Hero: 960w нұсқалары, сол жағдай | 365,426 kB | 89,734 kB |
| Hero: 1600w нұсқалары, сол жағдай | 1065,816 kB | 305,956 kB |

Барлық JS көлемі жүктеу/қате күйлері мен жеке чанктардың қосылуынан сәл өсті; бастапқы index азайды. CSS те сәл өсті. Барлық чанктар бастапқы экранға бірге жүктелмейді. Суреттердің сақталатын көлемі азайтылған жоқ: тиісті өлшемді таңдау және кейінге қалдыру жүктемені азайтады. Нақты нұсқаны браузер viewport пен DPR бойынша таңдайды. Hero кестесі қалыпты анимация режиміне арналған; reduced-motion алғашқы сурет жүктелген соң келесі бір суретті жылытады. Prerender HTML бастапқыда екі нұсқада да бір Hero суретін береді.

Архивтегі public суреттері build-ке дейін 21 047 052 байт болды; жобаның бұрыннан бар assets скрипті 36 responsive нұсқа жасайды. Сондықтан екі production build те 24 860 424 байт сурет қамтиды. Үлкен PNG/JPG түпнұсқалары және қайталанатын форматтар өшірілген жоқ; файлдардың дискіде болуы олардың бәрі браузерде жүктелетінін білдірмейді.

## Тексерулер

- npm run lint — өтті.
- npm test — 88/88 өтті, 0 fail, 0 skipped. Бастапқы жиынтықта 82 тест бар еді.
- npm run build — өтті; 32 public/404 құжат prerender жасалды; 30 public HTML беті, локализацияланған 404 және mobile image budget тексерілді.
- Қосылған регрессиялар: Hero бастапқы сурет саны/priority, алдын ала жүктеу шектері/декодтауды күту/кері scroll; reduced-motion; lazy loading/қате/Escape/фокус; loading → дайын модаль кезінде фокус; салыстыру модалінен фокустың қайтуы; көпкүндік мерзімнің RU/KZ формасы мен WhatsApp-қа берілуі.
- Жергілікті Vite браузерінде 390×844 және 1440×900 өлшемдері қолданылды: басты бет, Hero сахнасы, RU/KZ ауысуы, каталог, таңдалған тур формасы, салыстыру модалі қаралды. Сторис lightbox ашылуы, мобильді көрінісі және Escape арқылы жабылып, триггерге фокустың қайтуы тексерілді. Нақты өтінім жіберілген жоқ.

## Шектеулер

- Lighthouse, нақты телефон, CPU throttling және баяу мобильді желідегі уақыт өлшенбеді. Жылдамдық пайызы немесе Lighthouse ұпайы берілмейді.
- TourDetails үшін бастапқы DestinationPage кодында onOpenTourDetails пропсы жарияланғанымен қолданылмайды; сондықтан бұл модальды интерфейс арқылы қолмен ашу мүмкін болмады. Оның lazy чанкы build ішінде бар; ортақ модаль механикасы регрессиялық тесттермен тексерілді. Бұл навигация логикасы өзгертілмеді.
- VITE_SITE_URL бұрынғыдай орнатылмаған, сондықтан build canonical URL/sitemap қосуды ескертеді.
- Орнатудың алғашқы әрекеті DNS ENOTFOUND қатесіне ұшырады; желіге рұқсаттан кейін npm ci сәтті аяқталды. Соңғы lint/test/build бұғатталған жоқ.

## Қолдану

ZIP ішінде бастапқы жоба, өзгертілген код, тесттер және осы есеп бар; node_modules және dist кірмейді. Node >=22.13.0 орнатып, npm ci, npm run lint, npm test, npm run build орындаңыз. Қарау үшін npm run preview қолданылады. Өзгерістерді бөлек көру үшін ALL-TOUR-optimization.patch берілген.
