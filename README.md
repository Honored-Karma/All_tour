# ALL TOUR

Сайт туров из Алматы на React, TypeScript и Vite. Русская и казахская версии, каталог, подбор тура, избранное, сравнение, WhatsApp и локальная база заявок.

## Локальный запуск

Нужен Node.js 22.13+ (проверено на 22.22). SQLite в Node 22 выводит предупреждение ExperimentalWarning.

```bash
npm ci
npm run dev
```

Сайт: http://127.0.0.1:3000/. Сервер заявок запускается вместе с сайтом. Панель: http://127.0.0.1:4311/admin. База: `.data/leads.sqlite`; она исключена из Git. Телефон в локальной форме обязателен. После сохранения заявки открывается подготовленное сообщение WhatsApp, которое отправляет сам клиент. При ошибке сохранения форма показывает ошибку и отдельную ссылку WhatsApp.

Панель позволяет искать заявки, менять статус и сохранять заметки. Повторная отправка одной заявки не создаёт дубль; одновременные изменения защищены проверкой версии. Панель работает только на этом компьютере, без учётных записей. Для публикации сервера нужны авторизация, HTTPS, резервное копирование и правила обработки персональных данных.

```bash
npm run leads          # только сервер заявок
npm run leads:backup   # согласованная копия SQLite в .data/backups/
npm run content:edit   # редактор выездов: http://127.0.0.1:4310/
```

Редактор сохраняет `src/data/departures.json`, проверяет данные и делает копию предыдущей версии в `.cache/content-backups`. Изменения публикуются после новой сборки. Базу и резервные копии следует хранить в закрытом месте. Восстановление выполняется при остановленном сервере заменой базы согласованной копией.

## Данные и источники

- `src/data/departures.json` — объявления выездов: даты, цена именно этого выезда, источник и дата проверки. Начавшиеся, отменённые и распроданные выезды не показываются как предстоящие.
- `src/data/tours.ts` — описания программ. Программа в каталоге не означает наличие ближайшего выезда; неподтверждённые даты и стоимость показываются по запросу.
- `src/data/instagramResearch.json` — проверенные ссылки на Instagram и Telegram.
- `src/config/business.ts` — контакты компании.

Проверка Instagram и задачи перед публикацией: [отчёт](docs/instagram-and-launch-2026-10-28.md). Исходный аудит: [docs/project-audit-2026-10-27.md](docs/project-audit-2026-10-27.md).

## Проверка и сборка

```bash
npm run lint     # строгая проверка TypeScript
npm test         # все *.test.ts и *.test.tsx внутри src
npm run build    # WebP, Vite, статический HTML, проверка результата
npm run preview  # http://127.0.0.1:4173/
```

Сборка содержит 15 публичных страниц на каждом языке и две локализованные страницы 404. Оптимизированные изображения генерируются из оригиналов в `public/media/optimized`. Настройки Vercel и Netlify сохраняют выбор `?lang=kz` и настоящий статус 404 для неизвестных адресов. CI выполняет npm ci, проверку типов, тесты и сборку.

Скопируйте `.env.example` в `.env.local`, если нужны настройки. `VITE_SITE_URL` задаётся после выбора домена: без него canonical и sitemap не генерируются. `VITE_LEAD_CAPTURE` по умолчанию включает SQLite при разработке и выключает её для статического хостинга. Для production с заявками включите её явно и разместите совместимый сервер `/api`; конфигурации Vercel/Netlify этого сервера не разворачивают.

События воронки отправляются в `window.dataLayer` и `alltour:analytics`; внешний провайдер аналитики пока не подключён. Имена, телефоны, комментарии и текст сообщений в события не попадают. Источник заявки сохраняется по разрешённым UTM-полям.
